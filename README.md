## このプログラムについて

このプログラムは、**カメラとAI（人工知能）を用いて車両などの接近を検知し、警報信号を出力するリアルタイム安全管理システム**です。
工場や倉庫などの通路、見通しの悪い交差点に設置したカメラの映像から、AIがリアルタイムでフォークリフトやトラックなどの対象車両を検知し、指定されたエリア（ROI: 監視エリア）に侵入した際にパトライトやブザーなどの警報装置を作動（GPIO出力）させます。

---

## 主な機能

1. **AIによるリアルタイム車両検知**
   * 高速・軽量なAIモデル（YOLO / NCNN）を利用して、フォークリフトやトラック等の対象物を高精度に認識します。
   * 指定した確信度（しきい値）以上の検出をカウントします。

2. **直感的な監視エリア (ROI) の調整**
   * メイン画面のカメラプレビュー上をドラッグ操作するだけで、監視エリア（ROI）の範囲を視覚的かつ容易に変更・設定できます。

3. **ハードウェア連携と柔軟な警報出力制御 (GPIO)**
   * **接近検知出力 (NG)**: 車両の侵入を検知した際、警報装置を鳴らすためのGPIO信号を出力します。
   * **自動OFFタイマー**: 警報時間（秒）を設定することで、接近開始から指定秒数後に自動で警報信号をOFFにできます。空欄にすると、車両がエリアから退出するまで常時ONを出力し続けます。

4. **パソコンでのテスト・デバッグ機能 (モックモード)**
   * WindowsパソコンなどGPIO非対応の環境では、自動で「仮想GPIO/デバッグパネル」が起動します。
   * **ダミー接近検知機能**を搭載しており、カメラ映像に頼ることなくボタン一つで接近状態をシミュレートし、警報動作を確認できます。

5. **自動ディスク容量監視**
   * 保存画像がディスクを圧迫するのを防ぐため、古い画像から順に自動でクリーンアップする自動削除機能を搭載しています。

## 動作フロー（接近検知の流れ）

本システムは以下のフローで常時接近監視を行います。

```
 起動
  │
  ├─ 設定ファイル読み込み (inspection_settings.json)
  ├─ 保存先フォルダの自動生成 (results/)
  ├─ AIモデル（YOLO）のロード & ウォームアップ
  ├─ カメラの初期化（スレッドセーフな並列読み込み）
  └─ GPIOピンの初期化（警報出力用）
          │
          ▼
 [リアルタイム監視ループ]
  カメラ映像の取得
          │
          ▼
  AIによる物体検出 (YOLO)
          │
          ▼
  監視エリア（ROI）の判定
  ├─ ROI内に対象が存在する ──> 連続検知フレーム数をカウント
  └─ ROI内に対象が存在しない ─> カウンタをリセット (0)
          │
          ▼
  警報状態の判定
  ├─ 連続検知数が基準値（フレーム数）以上 ──> 【警報開始】
  │                                           ├─ NG警報出力ピンをON
  │                                           ├─ 接近中画像を自動保存
  │                                           └─ 設定時間経過で自動OFF (タイマー設定時)
  │
  └─ 連続検知数が基準値未満 (エリア外へ退出) ─> 【警報解除】
                                              └─ NG警報出力ピンをOFF
```

## ユーザー操作ガイド

### 1. 監視エリア (ROI) の調整
メイン画面に表示されているカメラ映像のプレビュー領域を、マウスの左ボタンを押したままドラッグすることで、赤い枠（ROI）を再描画できます。検出したいエリアを囲むように調整してください。

### 2. 詳細設定（詳細設定ボタン）
画面右側の「詳細設定」ボタンから、システムの挙動を調整できます。

| タブ | 設定内容 |
|---|---|
| カメラ設定 | 使用するカメラのインデックス番号の設定（単一カメラ固定）。テスト映像の確認。 |
| GPIOピン設定 | 警報出力 (NG) を行うGPIOピンの番号（BCM）の指定と、配線図（40Pin Map）の参照。設定画面内のテスト出力ボタンでON/OFF切り替え。 |
| 画素数設定 | カメラ解像度、画面のプレビュー解像度、接近検知画像および手動撮影画像の保存画素数設定。 |
| システム最適化 | AIモデルのパス、検出時の判定しきい値、警報出力持続時間（自動OFF秒数）、撮影モードの連続撮影枚数・間隔設定。 |
| 容量監視 | 保存画像の最大容量制限（GB）および自動削除の有効/無効設定。 |

## 結果フォルダ構成

```
results/
├── images/
│   ├── DETECT/      # 接近検知時に自動保存された画像（AI検出枠付き）
│   └── REC/         # 撮影モードで手動撮影した画像
├── csv/
│   └── inspection_results_YYYYMMDD.csv   # 日別の接近検知CSVログ
└── logs/
    └── app_YYYYMMDD.log                  # 日別のシステム動作ログ
```

### 接近検知画像の命名規則（DETECT）
```
DETECT_{YYYYMMDDHHMM}_{最大確信度}.jpg
```

### 撮影モード画像の命名規則（REC）
```
REC_{YYYYMMDD_HHMMSS_mmm}_{連番2桁}.jpg
```
